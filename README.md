# 🥗 NutriQuest AI

**🤖 An AI-Powered Gamified Nutrition & Healthy Eating Assistant.**

## 📖 About

NutriQuest AI is a software engineering project that aims to promote healthier eating habits by combining Artificial Intelligence (AI) with Gamification.

The project focuses on personalized meal recommendations, nutrition tracking, and interactive challenges to make healthy eating easier and more engaging.

## 🎯 Project Goals

- 🥑 Encourage healthier eating habits.
- 🤖 Provide personalized nutrition recommendations.
- 📊 Help users track their eating habits.
- 🏆 Improve motivation through gamification.

## 🚧 Project Status

Currently in the planning and requirements analysis phase.
